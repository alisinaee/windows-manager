Third alpha of Windows Manager for macOS. Built by GitHub Actions.

**What's new since alpha.2**
- **Fixed-size apps are respected.** The first time it sees an app, Windows Manager checks which widths and heights the app accepts (System Settings, V2Box and similar) and remembers it. Profile Studio no longer lets you resize those windows to sizes the app refuses.
- **New look.** The app now has its own icon. Profile Studio has a native toolbar, a native sidebar and Details panel, glass zoom and edit controls over the map, a right-click menu on profiles, and the map is centred when it opens.
- **Keyboard first.** All Studio shortcuts are in the menu bar (Edit > Undo works), ⌘K opens a command palette to find and run any profile, and the menu bar popup works with the arrow keys and shows each profile's shortcut.
- **Settings** now use a sidebar like System Settings, with grouped sections.
- **Undo for deletes.** Deleting a profile or layout shows an Undo banner; undo brings the profile back with its shortcut intact.
- Accessibility: text follows system size settings, animations stop with Reduce Motion, better VoiceOver labels.

**This alpha is not notarized and is ad-hoc signed.** Install:

1. Open the DMG and drag **Windows Manager** to **Applications**.
2. Run once in Terminal:
   ```
   xattr -dr com.apple.quarantine "/Applications/Windows Manager.app"
   ```
3. Open the app and grant **Accessibility** when asked. If you had an older alpha, remove its old entry in System Settings > Privacy & Security > Accessibility and grant it again.

Requires macOS 26 or newer, Apple silicon. Optional CLI: download `wm-0.1.0-alpha.3-arm64.zip`, unzip, `xattr -dr com.apple.quarantine ./wm`, move it to `/usr/local/bin`, then run `wm agent-guide`.

Found a bug? Menu bar icon or Settings > About > **Report a Bug…**, or `wm report`.

SHA-256 sums are in `SHA256SUMS.txt`.
